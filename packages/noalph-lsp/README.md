# @alphaisyour/lsp (Roadmap)

Paket ini direncanakan sebagai Language Server Protocol (LSP) untuk komponen `.eno`, menyediakan fitur auto-completion, hover diagnostics, dan go-to-definition di editor kode (VS Code, Neovim, dsb).

## Status Pengembangan
- **Status:** Direncanakan (Roadmap).
- **Diskusi & RFC:** Buka [GitHub Discussions](https://github.com/AlphaIsYour/noalphjs/discussions) jika kamu tertarik mengeksplorasi implementasi LSP untuk `.eno`.
